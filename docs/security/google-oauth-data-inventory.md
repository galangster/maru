# Google OAuth data inventory

## Retention rule

Wren keeps the local cache while the account remains connected. Initial sync and recovery sync select a 90-day Gmail window. The code does not promise an exact age-based purge on every incremental sync. Sources: `site/privacy.html:62-67`, `src/core/sync/engine.ts:38`, `src/core/sync/engine.ts:146-168`, and `src/core/sync/engine.ts:318-329`.

Account removal deletes cached mail rows, the account row, labels, and sync state. It destroys the account key, deletes OAuth tokens, and removes search-index entries. The in-app **Delete local Google data** action runs this account-removal path for every connected account. Sources: `src/core/store/db.ts:658-669`, `src/core/service/real.ts:305-313`, and `src/features/settings/settings-dialog.tsx:309-324`.

## Restricted-data inventory

| Google-derived data class | Local location | At-rest state | Retention | Deletion or erasure |
| --- | --- | --- | --- | --- |
| Message bodies | SQLite `messages.body_html`, `messages.body_text` | AES-256-GCM ciphertext | Cached while the account is connected. Bodies load on demand after metadata sync. | Account removal deletes `messages` rows and destroys the account key. The all-account action invokes the same removal path. Sources: `src/core/store/db.ts:75-100`, `src/core/store/db.ts:255-269`, `src/core/store/db.ts:809-900`, and `src/core/store/db.ts:658-669`. |
| Message headers and addresses | SQLite `messages.from_json`, `to_json`, `cc_json`, `bcc_json`, `reply_to_json`, `rfc_message_id`, `references_hdr`, and `in_reply_to`; SQLite `threads.participants` | AES-256-GCM ciphertext | Cached while the account is connected. | Account removal deletes `messages` and `threads`, then destroys the key. Sources: `src/core/store/db.ts:49-100`, `src/core/store/db.ts:253-269`, and `src/core/store/db.ts:658-669`. |
| Subjects | SQLite `threads.subject` and `messages.subject`; account-bound audit summaries can also contain a subject | AES-256-GCM ciphertext | Mail copies remain while the account is connected. Audit rows keep their structure, but not readable mail content, after removal. | Account removal deletes thread and message copies. Key destruction makes the audit summary unreadable. Sources: `src/core/store/db.ts:49-100`, `src/core/store/db.ts:616-620`, `src/core/agents/store.ts:304-329`, and `docs/PERMISSION-MODEL.md:258-271`. |
| Snippets | SQLite `threads.snippet` and `messages.snippet` | AES-256-GCM ciphertext | Cached while the account is connected. | Account removal deletes the rows and destroys the key. Sources: `src/core/store/db.ts:49-100`, `src/core/store/db.ts:253-269`, and `src/core/store/db.ts:658-669`. |
| Attachment metadata | SQLite `messages.attachments` stores JSON metadata, including filenames, media types, sizes, and Gmail attachment identifiers | AES-256-GCM ciphertext, except the empty `[]` value | Cached while the account is connected. | Account removal deletes the message rows and destroys the key. Sources: `src/core/store/db.ts:75-100`, `src/core/store/db.ts:255-269`, `src/core/store/db.ts:817-899`, and `tests/crypto.test.ts:66-150`. |
| Attachment contents | No durable store. `getAttachment` returns bytes from Gmail to the active caller. | Not applicable at rest. Google transit uses the Gmail request path. | Process memory for the request and response only. | Wren has no durable attachment-content row to delete. The data leaves memory with the request lifecycle. Sources: `src/core/gmail/api.ts:267-273` and `src/core/service/real.ts:339-345`. |
| Label names | SQLite `labels.name` | AES-256-GCM ciphertext | Cached while the account is connected. | Account removal deletes `labels` rows and destroys the key. Sources: `src/core/store/db.ts:102-109`, `src/core/store/db.ts:618-620`, and `src/core/store/db.ts:999-1039`. |
| Label identifiers and message state | SQLite `threads.label_ids`, `thread_labels.label_id`, `messages.label_ids`, `unread`, and `starred` | Plaintext | Cached while the account is connected. | Account removal deletes `thread_labels`, `threads`, and `messages`. Sources: `src/core/store/db.ts:49-100` and `src/core/store/db.ts:658-669`. |
| Gmail message and thread identifiers | SQLite `messages.id`, `thread_id`, and `thread_key`; SQLite `threads.key` and `gmail_thread_id`; account-bound audit `thread_key` is encrypted | Mail-table identifiers are plaintext so the store can join, fetch, and update records. The audit thread reference is ciphertext. | Cached while the account is connected. Audit structure remains after removal. | Account removal deletes mail rows. Key destruction erases the audit thread reference. Sources: `src/core/store/db.ts:49-100`, `src/core/agents/store.ts:304-329`, and `docs/PERMISSION-MODEL.md:258-271`. |
| Gmail history identifiers | SQLite `sync_state.history_id` | Plaintext cursor used for incremental sync | Retained while the account is connected and replaced as Gmail returns a newer cursor. | Account removal deletes `sync_state`. Sources: `src/core/store/db.ts:111-115`, `src/core/store/db.ts:1048-1068`, and `src/core/sync/engine.ts:209-245`. |
| Gmail profile address | SQLite `accounts.email`. `display_name` initially derives from the address prefix. | Plaintext so the app can identify and route accounts | Retained while the account is connected. | Account removal deletes the `accounts` row. Sources: `src/core/auth/oauth.ts:450-457`, `src/core/service/real.ts:269-297`, and `src/core/store/db.ts:41-47`. |
| Agent send drafts derived from Gmail or user input | SQLite `approvals.payload_json`, with `account_id` beside it | Payload is AES-256-GCM ciphertext. Status, timestamps, agent id, kind, and account id are plaintext. | Pending requests expire after 24 hours. Resolved rows remain for history while their account key exists. | Account removal expires pending rows and destroys the key. The encrypted payload becomes unreadable. Sources: `src/core/agents/approvals.ts:27`, `src/core/agents/approvals.ts:172-201`, `src/core/agents/store.ts:252-299`, and `src/core/store/db.ts:658-669`. |
| OAuth access and refresh tokens | Operating-system keychain entry `wren:account:<account-id>` | Protected by the operating-system keychain, never SQLite | Retained while the account is connected. Access tokens can refresh in memory and the keychain. | Account removal calls `TokenStore.clear`. The all-account deletion action repeats that path for all accounts. Sources: `src/core/auth/oauth.ts:256-301`, `src/core/service/real.ts:305-313`, and `SECURITY.md:29-30`. |

The local full-text search index is in process memory. Account removal discards that account's thread keys from it. Sources: `src/core/service/real.ts:162-168`, `src/core/service/real.ts:305-313`, and `src/core/search/index.ts:35-45`.

> NOTE: Part 2 §3 of `docs/research/shared-client-implementation-plan.md` requires encryption for restricted data at rest. Current code leaves the profile address, Gmail identifiers, label identifiers, history cursor, dates, and state flags in plaintext. The implementation must resolve this gap or document Google's acceptance before submission.

> NOTE: `site/privacy.html:42` describes attachments as stored in the encrypted local database. Current code stores encrypted attachment metadata, but it does not persist attachment bytes. Public wording should distinguish metadata from attachment contents.
