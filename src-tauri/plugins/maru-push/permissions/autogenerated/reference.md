## Default Permission

Allows Maru to register for push, read its notification permission, and post the local notification it composes on the phone

#### This default permission set includes the following:

- `allow-start`
- `allow-permission-state`
- `allow-request-permission`
- `allow-token`
- `allow-set-badge-count`
- `allow-schedule-local-notification`
- `allow-complete-push`
