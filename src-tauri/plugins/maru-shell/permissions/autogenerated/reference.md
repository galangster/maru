## Default Permission

Allows Maru to drive its native iOS tab bar and haptics

#### This default permission set includes the following:

- `allow-select-tab`
- `allow-set-badge`
- `allow-set-tab-bar-hidden`
- `allow-impact`
- `allow-notify`
- `allow-prepare-haptics`
- `allow-watch-tabs`
- `allow-unwatch-tabs`
