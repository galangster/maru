## Default Permission

Allows Maru to start its iOS browser authentication session

#### This default permission set includes the following:

- `allow-start-auth-session`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`maru-auth:allow-start-auth-session`

</td>
<td>

Enables the start_auth_session command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`maru-auth:deny-start-auth-session`

</td>
<td>

Denies the start_auth_session command without any pre-configured scope.

</td>
</tr>
</table>
