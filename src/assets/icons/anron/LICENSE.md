# Anron icon set — license

The glyphs in this directory are from Anron, Nick Galang's own icon
library. **All rights reserved.** They are licensed for use and
redistribution **only as part of Wren builds** — official or forked — and
not for extraction or use in other projects.

Forks that prefer fully-free assets can remove this directory: every icon
routes through the seam in `src/components/ui/icon.tsx`, which falls back
to [lucide](https://lucide.dev) (ISC) glyph-for-glyph.
